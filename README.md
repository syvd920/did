# 공인중개사 광고 제작기 v2

GitHub Pages에 바로 올릴 수 있는 정적 웹앱입니다.

## 규격
- 가로형: 1400 x 1080
- 세로형: 1080 x 1300
- 템플릿: 5종

## 중개사가 수정 가능한 항목
- 매물 사진
- 메인 카피
- 서브 카피
- 가격/조건
- 공인중개사명
- 연락처
- 강조 색상

## 중개사가 수정할 수 없는 항목
- 텍스트 위치
- 텍스트 크기
- 폰트
- 전체 레이아웃
- 디자인 요소 배치

## 파일
- index.html : 중개사용 제작기
- templates.js : 관리자 템플릿 설정
- admin.html : 관리자 안내
- README.md

## GitHub Pages 배포
1. 새 GitHub repository 생성
2. 이 폴더의 파일을 repository 루트에 업로드
3. Settings > Pages
4. Deploy from a branch 선택
5. main / root 선택 후 저장
