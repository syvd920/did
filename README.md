# 공인중개사 광고 제작기 v3

## 관리자
- 템플릿 이름 직접 지정
- 사진 있음 / 사진 없음 선택
- 사진 있음일 때 1 / 2 / 3 / 4 / 6분할 선택
- 가로 1400×1080 / 세로 1080×1300 편집
- 글씨 요소 드래그 이동
- 글씨별 크기 / 색상 / 굵기 / 정렬 변경
- 브라우저 localStorage 저장
- templates.json 내보내기

## 중개사
- 관리자 템플릿 선택
- 가로 / 세로 선택
- 사진 템플릿이면 필요한 수만큼 사진 업로드
- 사진 없는 템플릿이면 사진 입력란 없음
- 문구 입력 후 PNG 다운로드

주의: GitHub Pages는 정적 호스팅이라 관리자에서 저장한 localStorage 설정이 다른 사용자에게 자동 배포되지는 않습니다.
실제 배포 시에는 관리자에서 완성한 템플릿 설정을 templates.js에 반영해 올리는 방식이 필요합니다.
