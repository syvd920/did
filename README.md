# 공인중개사 광고 제작기 v5

중개사 입력 항목
1. 매물 구분: 매매 / 월세 / 전세
2. 매물명
3. 평
4. 방 / 욕실 개수
5. 매물설명: 최대 2줄 표시

중개사 글씨 조정
- 각 항목별 글씨 종류
- 각 항목별 글씨 색상
- 각 항목별 글씨 크기
- 관리자 템플릿 설정이 기본값

사진
- 비율이 맞지 않아도 자르지 않음
- 사진 전체가 보이도록 contain 방식 리사이징
- 사진 슬롯 중앙 정렬

방향 표기
- 가로버전
- 세로버전

관리자
- 배경 디자인 업로드
- 사진 있음/없음
- 1/2/3/4/6분할
- 사진 슬롯 위치/크기 조정
- 글씨 기본 위치/폰트/색상/크기 설정
