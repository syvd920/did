# 공인중개사 광고 제작기 v4

핵심 변경:
- 관리자에서 템플릿별 실제 배경 디자인 PNG/JPG 업로드
- 가로/세로 배경 별도 지정
- 사진 있음/없음
- 1/2/3/4/6분할 사진 슬롯
- 사진 슬롯을 배경 디자인 위에 직접 배치
- 텍스트를 배경 디자인 위에 직접 배치
- 텍스트별 색상/크기/굵기/정렬 개별 설정
- 중개사 화면에서는 관리자 디자인 그대로 사용

배포 방식:
1. admin.html에서 템플릿 편집
2. '템플릿 파일 내보내기'로 published-templates.js 생성
3. GitHub의 published-templates.js 교체
4. index.html에서 모든 사용자에게 동일 템플릿 적용
